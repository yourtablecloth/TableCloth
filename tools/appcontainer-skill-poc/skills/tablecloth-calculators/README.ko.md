# 식탁보 금융 및 생활 계산기

[English](README.md) | [저작권과 독립 구현 기준](docs/COPYRIGHT.ko.md) | [기여 안내](CONTRIBUTING.ko.md)

`tablecloth-calculators`는 Codex 스킬과 로컬 Python 계산기를 제공합니다. 표시 이름으로 **금융 및 생활 계산기**를 사용합니다. 계산기는 사용자가 제공한 값으로 계산하며 웹 요청, 외부 데이터셋, API 키나 외부 Python 패키지를 사용하지 않습니다.

공개 계산 방법을 바탕으로 구현합니다. 제3자의 소스 코드, 화면, 설명문, 보고서와 데이터셋은 이 패키지의 재사용 범위에서 제외합니다. [저작권 안내](docs/COPYRIGHT.ko.md)에서 독립 구현과 기여 기준을 설명합니다.

## 입력값과 계산 범위

[계산 연산 안내](references/operations.md)는 지원 연산, JSON 필드, 단위, 가정과 반올림 기준을 제공합니다. 금융 계산은 사용자가 제시한 수치로 산술 결과를 구하며 개인별 금융 상품이나 투자를 추천하지 않습니다. 기본 BMI 계산은 수치만 반환하고 건강 분류나 인구집단 비교를 제공하지 않습니다.

세금, 법정 급여, 규제 적격성, 실시간 금리와 시세, 공휴일과 음력, 지역별 일광절약시간 데이터, 의학적 해석, 특정 사이트의 PRO 분석과 보고서를 제외합니다. PRO 표시만으로 공개 계산 방법에 대한 법적 독점권을 판단하지 않습니다.

## 저장소 루트의 스킬 설치

식탁보의 설치된 스킬 화면에서 이 폴더를 가져올 수 있습니다. 카탈로그에 등록한 뒤에는 스킬 마켓플레이스에서도 설치할 수 있습니다. 루트에 [SKILL.md](SKILL.md)를 두므로 카탈로그는 `Source.Path="."`와 전체 커밋 해시를 사용합니다. 스킬 설치는 Python 설치나 전역 설정 변경을 수행하지 않습니다.

계산기는 Python 3.11 이상에서 실행합니다. 식탁보에서는 전용 Python 런타임을 설치하고 `KSKILL_PYTHON`으로 전달한 절대 경로를 사용합니다. 식탁보 외부에서는 실행할 Python의 절대 경로를 직접 지정합니다. pip 패키지나 추가 서비스 자격 증명을 요구하지 않습니다.

## 계산 요청과 실행 권한

백분율이나 할인액처럼 지원하는 계산을 Codex에 요청할 수 있습니다. [스킬 지침](SKILL.md)은 요청을 [scripts/calculate.py](scripts/calculate.py)로 전달하며 표준 입력으로 JSON 요청 하나를 보냅니다. 식탁보가 `KSKILL_PYTHON`을 전달한 실행 환경에서 다음 PowerShell 예제를 사용할 수 있습니다. 스크립트 경로는 설치한 스킬의 절대 경로로 바꿉니다.

```powershell
$request = '{"operation":"discount.single","price":"100","rate_percent":"20"}'
$request | & $env:KSKILL_PYTHON -I -S -B 'C:\absolute\skill\scripts\calculate.py'
```

해당 변수가 없는 별도 터미널에서는 `$env:KSKILL_PYTHON` 대신 선택한 Python의 절대 경로를 사용합니다. `-I -S -B`는 Python 가져오기 경로를 격리하고 site 초기화와 바이트코드 파일 생성을 생략합니다. 이 요청은 `ok: true`와 `result.final`의 `"80.00"`을 반환합니다. 소수 문자열로 숫자를 전달하면 입력 단계의 의도하지 않은 반올림을 줄일 수 있습니다. [계산 연산 안내](references/operations.md)에서 전체 입력과 출력을 확인할 수 있습니다. 잘못된 입력에는 `ok: false`와 종료 코드 2를 반환합니다. 실행에 실패하면 제한이나 수정할 입력값을 설명하며 추측한 결과를 제시하지 않습니다.

계산 CLI는 네트워크 요청을 보내지 않습니다. 다만 Codex 대화는 온라인 계정 연결을 사용하고 대화 내용을 공급자에게 전송할 수 있습니다. 셸 실행 권한은 이 계산 스크립트보다 넓은 실행 범위를 허용하며 스킬 지침만으로 Python 전용 보안 경계를 강제할 수 없습니다. 식탁보의 실행 권한을 그대로 적용합니다.

기여 과정에서는 [기여 안내](CONTRIBUTING.ko.md)에 따라 출처, 라이선스와 독립 구현 경위를 밝히고 유지 관리자의 검토를 거칩니다. 사이트 콘텐츠의 복제나 번역, 제3자 코드의 재작성, PRO 서비스 복제와 데이터 표 추출을 제출하지 않습니다.

저장소 루트에서 Python 3.11 이상으로 표준 라이브러리 테스트를 실행할 수 있습니다.

```text
python -m unittest discover -s tests -v
```

[CI 워크플로](.github/workflows/test.yml)는 Linux와 Windows에서 Python 3.11, 3.14로 같은 테스트를 실행합니다. 패키지 게시나 서비스 배포는 수행하지 않습니다.
