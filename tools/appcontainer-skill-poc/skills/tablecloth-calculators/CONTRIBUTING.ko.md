# 독립 구현 계산기의 기여 기준

[English](CONTRIBUTING.md) | [README](README.ko.md) | [저작권 안내](docs/COPYRIGHT.ko.md)

이 프로젝트는 사용자가 제공한 값을 계산하는 표준 라이브러리 기반의 독립 구현을 받습니다. 유지 관리자는 각 기여의 범위, 출처, 라이선스와 테스트를 검토한 뒤 반영합니다.

## 외부 서비스와 데이터셋 없는 계산

공개 계산 방법, 입력값, 단위, 가정과 반올림 기준을 설명합니다. 실제 JSON 입력과 출력, 예제를 [계산 연산 안내](references/operations.md)에 추가합니다. Python 3.11 이상을 지원하며 다운로드, 네트워크 요청, API 키, 환경 변수로 받는 자격 증명과 pip 의존성을 추가하지 않습니다.

세금과 규제 계산, 법정 급여, 최신 금리와 시세, 공휴일과 음력, 지역별 일광절약시간 데이터, 의학적 분류, 진단과 치료를 제외합니다. 기본 BMI는 비교 집단이나 임상 분류를 가져오지 않고 수치만 구할 수 있습니다. 특정 사이트의 PRO 업무 흐름, 분석과 보고서를 복제하지 않습니다.

## 기여별 출처와 권리 확인

PR에는 다음 내용을 포함합니다.

- 직접 구현한 작성자와 참고 자료
- 공개 공식이나 사양의 1차 출처 링크와 해당 버전 또는 기준일
- 제안한 비원본 자료 각각의 라이선스와 이용 조건 또는 비원본 자료를 포함하지 않았다는 설명
- 구현, 가정, 반올림과 테스트 사례를 독립적으로 도출한 경위
- 변경 동작의 테스트 명령과 결과

공개된 자료나 익숙한 공식이라고 해서 다른 구현을 복제할 권한까지 얻지는 않습니다. 제3자의 소스 코드, 화면 구성, 도움말, 보고서, 예제와 데이터셋을 복제, 번역, 문장 바꾸기나 코드 재작성으로 가져오지 않습니다. 공개 수학 방법을 출처로 삼고 구현, 인터페이스와 설명은 독립적으로 작성합니다. PRO나 상표 표시만으로 특정 서비스가 일반 계산 방법을 소유한다고 주장하지 않습니다. [저작권 안내](docs/COPYRIGHT.ko.md)는 구분 기준을 설명하며 개별 구현의 법적 적합성을 보증하지 않습니다.

유지 관리자는 출처나 권리를 판단하기 어려운 자료에 추가 근거를 요청하거나 반영을 보류할 수 있습니다. 출처 표시만으로 제외 대상 자료를 허용하지 않습니다. 실제 자격 증명, 개인 금융 기록이나 건강정보를 코드, 테스트 자료, 문서, 이슈와 PR에 포함하지 않습니다.

## 검토 전 동작 검증

대표 결과, 잘못된 입력, 계산 범위와 반올림처럼 변경에 관련된 동작을 테스트합니다. 합성 입력과 독립적으로 도출한 예상값을 사용합니다. 테스트에서 제3자 계산기 서비스를 수집하거나 정답 비교 대상으로 호출하지 않습니다.

저장소 루트에서 표준 라이브러리 테스트를 실행할 수 있습니다.

```text
python -m unittest discover -s tests -v
```

[워크플로](.github/workflows/test.yml)는 Linux와 Windows에서 Python 3.11, 3.14를 검사합니다. [SKILL.md](SKILL.md), 계산 연산 안내와 두 언어의 README에 실제 구현과 같은 입력, 출력과 제한을 유지합니다.
