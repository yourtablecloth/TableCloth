1. 식탁보란 무엇인가요?

식탁보는 Windows Sandbox라는 일회용 가상 환경 안에서 인터넷 뱅킹이나 공공 사이트를 이용하도록 도와주는 무료 프로그램입니다. 은행·공공 사이트가 요구하는 보안 프로그램들을 내 실제 컴퓨터가 아니라 격리된 샌드박스 안에만 설치하므로, 사용을 마치고 샌드박스를 닫으면 그 안의 모든 것이 흔적 없이 사라집니다.

  • 내 PC에 보안 프로그램을 어지럽게 설치하지 않아도 됩니다.
  • 샌드박스는 매번 깨끗한 상태로 시작하고, 닫으면 초기화됩니다.
  • 즐겨찾기·사용 기록 등 꼭 유지하고 싶은 데이터만 별도 폴더에 남길 수 있습니다.

2. 시작하기 전에 (준비물)

식탁보는 Windows의 Windows Sandbox 기능을 사용합니다. 다음 조건이 필요합니다.

  • Windows 10/11 Pro·Enterprise·Education 에디션 (Home 에디션은 Windows Sandbox를 지원하지 않습니다)
  • Windows Sandbox 기능이 켜져 있어야 합니다. 꺼져 있으면 식탁보가 켜는 방법을 안내합니다.
  • BIOS/UEFI에서 가상화(Virtualization) 기능이 켜져 있어야 합니다.
처음 실행 시 Windows Sandbox 기능이 없으면, 식탁보가 기능 설치를 도와주고 재부팅을 안내합니다.

3. 빠른 시작

식탁보를 실행하면 빠른 시작 화면이 나옵니다. 몇 가지만 지정하고 바로 시작할 수 있습니다.

  1. 공동인증서 공유(선택) — 인터넷 뱅킹에 공동인증서가 필요하면, 옵션에서 공동인증서 폴더 공유를 켜 둡니다. 그러면 샌드박스에서도 인증서를 사용할 수 있습니다.
  2. 데이터 폴더(선택) — 즐겨찾기·사용 기록을 다음에도 유지하려면 데이터 폴더를 지정합니다. 기본값을 그대로 써도 됩니다.
  3. 함께 사용할 폴더(선택) — 샌드박스와 파일을 주고받을 폴더가 있으면 추가합니다.
  4. ‘샌드박스 시작’ 클릭 — 잠시 기다리면 격리된 샌드박스 환경이 뜹니다.
  5. 사이트 선택은 샌드박스 안에서 — 어떤 은행·공공 사이트를 이용할지는 샌드박스 안의 목록에서 고릅니다.
사이트 선택을 샌드박스 안에서 하도록 바뀌었기 때문에, 시작 화면에서는 최소한의 설정만 하면 됩니다.

4. 샌드박스 안에서 하는 일

샌드박스가 뜨면 그 안에서 식탁보 도우미(카탈로그)가 실행됩니다.

사이트 목록에서 고르기

  • 은행·카드·증권·공공 사이트 목록이 아이콘으로 나옵니다. 검색으로 빠르게 찾을 수 있습니다.
  • 사이트를 클릭하면 그 사이트에 필요한 보안 프로그램이 샌드박스 안에 설치되고, 이어서 사이트가 열립니다.
  • 자주 쓰는 사이트는 즐겨찾기(별 아이콘)로 표시해 두면 다음에 찾기 쉽습니다.

보조 프로그램

‘보조 프로그램’ 탭에서는 어도비 리더, 모두의 프린터 같은 도구의 공식 다운로드 페이지로 안내합니다. 저작권·이용약관 동의가 필요한 소프트웨어라, 다운로드·설치는 사용자가 직접 진행합니다.

공동인증서

공동인증서 공유를 켜 두었다면, 샌드박스 안에서 인증서 목록을 확인하고 뱅킹에 사용할 수 있습니다.

5. 옵션 살펴보기

시작 화면의 옵션… 을 누르면 다음 탭들을 볼 수 있습니다.

탭설명
사용자 폴더샌드박스와 공유할 폴더를 추가·삭제하고, 읽기 전용 여부를 설정합니다.
데이터 디렉터리즐겨찾기·사용 기록 등 계속 유지할 데이터를 저장할 호스트 폴더를 지정합니다. 로컬 고정 디스크를 권장합니다.
인증서공동인증서(NPKI) 폴더를 샌드박스와 공유할지 설정합니다. 인터넷 뱅킹의 핵심 옵션입니다.
장치 공유마이크·웹캠·프린터를 샌드박스에서 함께 쓸지 설정합니다. ‘프린터 연결’은 내 PC의 프린터를 공유하는 것으로, ‘모두의 프린터’ 같은 가상 프린터 앱 설치와는 다릅니다.
호환성샌드박스 GPU 가속을 켜고 끕니다. 기본은 꺼짐이며, 화면이 하얗게 나오는 문제 등을 피하기 위한 설정입니다.
진단문제 해결을 돕기 위한 로그 자동 수집을 설정합니다.

6. 미리 보기 기능 Preview

미리 보기 기능은 실험적이며 예고 없이 바뀌거나 사라질 수 있습니다. 원하는 분만 켜서 사용해 보세요.

자리 비움 시 자동 종료

설정한 시간 동안 키보드·마우스 입력이 없으면 샌드박스 세션을 자동으로 종료해, 인증된 뱅킹 세션을 자리 비운 사이 열어두는 위험을 줄입니다. 종료 직전 경고가 잠깐 표시되며, 아무 키나 누르거나 마우스를 움직이면 취소됩니다.

미리 보기 한계: 유휴가 감지되면 샌드박스 세션이 종료(로그아웃)되지만, Windows Sandbox 창 자체는 곧바로 닫히지 않을 수 있습니다. 세션은 종료된 상태이므로 창은 직접 닫아 주세요.

7. 자주 묻는 질문

샌드박스를 닫으면 설치한 프로그램은 어떻게 되나요?
모두 사라집니다. 샌드박스는 일회용이라, 닫는 순간 그 안의 프로그램·파일·설정이 초기화됩니다. 이것이 식탁보의 보안 장점입니다.
즐겨찾기나 기록은 매번 사라지나요?
아니요. 데이터 디렉터리로 지정한 폴더에 저장되며, 이 폴더는 읽기·쓰기로 연결되어 다음 실행에도 유지됩니다.
‘Windows Sandbox를 시작할 수 없습니다’ 라고 나옵니다.
Windows 에디션이 Pro 이상인지, Windows Sandbox 기능과 BIOS 가상화가 켜져 있는지 확인하세요. 이미 다른 샌드박스가 열려 있으면 하나만 실행할 수 있습니다.
공동인증서가 샌드박스에서 안 보입니다.
옵션 → 인증서 탭에서 ‘공동인증서 폴더 공유’가 켜져 있는지, 내 PC에 인증서 폴더가 실제로 있는지 확인하세요.
화면이 하얗게 나오거나 느립니다.
옵션 → 호환성 탭의 GPU 가속을 끈 상태(기본값)로 사용해 보세요. 일부 그래픽 환경에서 발생할 수 있습니다.
샌드박스는 열리는데 식탁보 창이 뜨지 않고 아무 메시지도 없습니다.
샌드박스 바탕 화면에 App·Data 폴더는 보이는데 그 뒤로 아무 일도 일어나지 않는 경우입니다. 샌드박스 안에서 바탕 화면 → App → StartupScript.cmd를 직접 실행했을 때 정상적으로 진행된다면, Windows Sandbox가 시작 시 실행하기로 한 명령을 무시하고 있는 상태입니다. 이때는 식탁보가 만든 파일이 아니라 Windows Sandbox 쪽 문제이므로, Windows 기능에서 ‘Windows Sandbox’를 끄고 재부팅한 뒤 다시 켜서 샌드박스 이미지를 초기 상태로 되돌려 보세요. 서드파티 백신을 쓰신다면 잠시 중지하고 시도해 보시는 것도 도움이 됩니다.
제보해 주실 때는 데이터 폴더에 남는 tablecloth-boot.log 파일을 함께 첨부해 주시면 큰 도움이 됩니다. 샌드박스 시작 과정이 어디까지 진행됐는지 기록되어 있습니다.

8. 보안과 주의사항

  • 식탁보는 격리 환경을 제공할 뿐, 피싱 사이트나 가짜 앱으로부터 무조건 보호해 주지는 않습니다. 주소와 인증서를 항상 확인하세요.
  • 공용 PC에서는 자리를 비울 때 반드시 샌드박스를 닫으세요. (미리 보기의 자동 종료 기능이 도움이 될 수 있습니다.)
  • 웹캠·마이크 공유는 개인정보 노출에 주의해서 꼭 필요할 때만 켜세요.
  • 데이터 디렉터리에는 민감한 파일을 두지 마세요. 이 폴더는 샌드박스와 읽기·쓰기로 연결됩니다.
