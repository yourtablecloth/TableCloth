# `tablecloth:` 딥링크 계약 (데스크톱 설치판)

> 상태: **구현됨 (2026-08-01)**. 설치판(모드 1)에서 브라우저의 링크 한 번으로 해당 사이트용 샌드박스를
> 띄우기 위한 커스텀 URI 스킴 계약. 무설치(모드 2)의 `.wsb` 딥링크는
> [PARAMETERIZED_WSB_SPEC.md](PARAMETERIZED_WSB_SPEC.md) §6.5 가 소유한다.

## 1. 형태

| 형태 | 예 | 동작 |
| --- | --- | --- |
| 사이트 Id | `tablecloth:wooribank` | 해당 카탈로그 서비스의 상세 화면으로 진입 |
| 대상 URL | `tablecloth:https://spib.wooribank.com/pib/Dream?withyou=CTCER0149` | 도메인 게이트 통과 시, 그 사이트의 보안 프로그램을 설치한 뒤 **그 주소**를 샌드박스 안에서 연다 |

- 스킴 이름과 사이트 Id 는 **대소문자를 가리지 않는다**(`tablecloth:WooriBank` = `tablecloth:wooribank`).
  호스트가 카탈로그의 정식 Id 로 정규화해 하위 단계에 넘긴다 — 하위 단계는 Ordinal 비교라 정규화가 없으면
  조용히 빈 선택이 된다.
- `tablecloth://…` 처럼 슬래시 두 개를 붙인 형태도 같은 의미로 받는다(사용자가 흔히 그렇게 적는다).
- **URL 은 퍼센트 디코딩하지 않는다.** 이미 인코딩된 주소(한글 질의문자열 등)를 한 번 더 디코딩하면
  원래 주소가 깨지기 때문이다. 스킴만 떼고 나머지는 원문 그대로 게이트로 넘어간다.
- 프래그먼트(`#…`)는 전달을 보장하지 않는다(브라우저가 떼는 경우가 있다).

## 2. 등록 (관리자 권한 불필요)

`HKCU\Software\Classes\tablecloth` 에 현재 사용자 범위로 등록한다. 앱 시작 시
`RegisterUriSchemeIfNeeded()`(`src/TableCloth/Program.cs`)가 수행하며, `.tclnk` 파일 연결 등록과 같은 방식이다.

```
HKCU\Software\Classes\tablecloth
  (기본값)                     = "URL:TableCloth Protocol"
  URL Protocol                 = ""          ← 이 값의 존재가 URI 스킴 처리기임을 표시
  DefaultIcon\(기본값)         = "<exe>",0
  shell\open\command\(기본값)  = "<exe>" --uri "%1"
```

- **승격이 필요 없는 이유**: HKCU 쓰기는 Vista 이후 승격 대상이 아니고, `TableCloth.exe` 의 매니페스트가
  `asInvoker` 라 브라우저가 링크로 실행해도 UAC 가 뜨지 않는다. (`requireAdministrator` 인 것은 샌드박스
  *안에서* 도는 `Spork.exe` 뿐이다.) Velopack 설치도 `%LOCALAPPDATA%` per-user 라 범위가 일치한다.
- **범위**: 등록한 사용자 계정에만 적용된다. 같은 PC 의 다른 계정은 그 계정에서 앱을 한 번 실행하면 등록된다.
- **조건**: Velopack 으로 설치된 경우에만 등록한다(파일 연결과 동일 기준). 포터블/개발 실행이 임시 경로를
  전역 스킴으로 등록해버리는 것을 막는다.
- **갱신**: 기존 `shell\open\command` 값이 현재 실행 파일 경로와 다르면 덮어쓴다(재설치/경로 이동 대응).
- `"%1"` 의 **큰따옴표는 필수**다. 없으면 셸이 공백 기준으로 인자를 쪼개 스위치 주입이 가능해진다.

## 3. 신뢰 모델

페이로드는 **임의의 웹 페이지가 넣는 값**이다. 방어선은 세 겹이다.

1. **argv 재해석 차단.** 진입점이 페이로드를 `TableClothUri` 파서에 통과시킨 뒤 **정규 인자로 다시 만들어서**
   넘긴다. 원문을 그대로 argv 에 흘리지 않는다 — 이 앱의 인자 파이프라인은 `@파일` **응답 파일 확장**을
   쓰고 있어서(바탕화면 `.tclnk` 연결이 그 기능에 의존한다), `tablecloth:@\\attacker\share\x.txt` 같은
   입력이 임의 경로(UNC 포함) 파일 읽기가 되기 때문이다. 그래서 사이트 Id 토큰은
   **영숫자로 시작**해야 하고(`@`, `-` 로 시작 불가) 이후 문자는 `[A-Za-z0-9._-]` 로 제한된다.
2. **카탈로그 도메인 게이트.** URL 형태는 `CatalogTargetUrlMatcher` 를 통과해야 한다(무설치 레인과 같은
   게이트, 같은 규칙). 카탈로그가 모르는 도메인이면 URL 을 버리고 평소처럼 앱만 연다.
3. **브라우저 확인창.** Chrome/Edge 가 "TableCloth 을(를) 여시겠습니까?" 를 띄운다. 없앨 수 없으며,
   임의 페이지의 무단 실행을 막는 사용자 확인 지점이므로 없애려 하지 않는다.

## 4. 이미 실행 중인 경우 (단일 인스턴스)

호스트 앱은 Global mutex 로 단일 인스턴스를 강제한다. 그래서 앱이 떠 있는 상태에서 링크를 누르면 두 번째
인스턴스가 "이미 실행 중" 오류로 끝나 링크가 무시된다. `IDeepLinkActivationChannel`(명명된 파이프)이 그
사이를 잇는다.

```text
브라우저 ──▶ TableCloth.exe --uri "tablecloth:…"   (두 번째 인스턴스)
                   │
                   ├─ 파이프 접속 성공 ─▶ 페이로드 전달 후 즉시 종료(코드 0)
                   │                         │
                   │                         ▼
                   │                    실행 중 인스턴스: 창 활성화 → 대상 사이트로 이동
                   └─ 접속 실패(앱이 없음) ─▶ 이 프로세스가 그 인스턴스가 된다
```

- 파이프 이름에 사용자 SID 를 넣어 계정별로 분리한다. 접근 제어는 명명된 파이프의 **기본 보안 서술자**에
  맡긴다 — 기본 DACL 이 생성자와 SYSTEM 에만 쓰기를 허용하므로 다른 계정이 페이로드를 밀어 넣을 수 없다.
- 접속 대기는 500ms. 앱이 안 떠 있는 흔한 경우에 사용자가 기다리지 않도록 짧게 잡았다.
- 앱이 **시작 중**(스플래시 단계)이면 파이프가 아직 열리지 않아 접속에 실패하고, 기존과 같은 "이미 실행 중"
  오류가 뜬다. 드문 경합이라 현재는 그대로 둔다.

## 5. 대상 URL 이 샌드박스까지 가는 경로

```text
tablecloth:https://…
  → TableClothUri 파서        (형태 검증, 정규 인자화)
  → CatalogTargetUrlMatcher   (카탈로그 도메인 게이트)
  → CommandLineArgumentModel.TargetUrl
  → TableClothConfiguration.TargetUrl
  → StartupScript.cmd:  TableCloth.exe spork <ids> --target-url "<url>"
  → Spork 가 설치 완료 후 그 주소를 연다 (무설치 레인과 동일한 코드 경로)
```

배치 파일에 URL 을 넣을 때 **두 가지를 인코딩**한다(`SandboxBuilder.EncodeTargetUrlForBatchFile`).

- **비 ASCII → 퍼센트 인코딩.** 스크립트는 UTF-8 로 기록되지만 cmd 는 OEM 코드페이지로 읽어, 비 ASCII 가
  섞이면 스크립트 전체가 무동작이 될 수 있다(이슈 #304 에서 실측된 함정, `StartupScript_ShouldBePureAscii`).
- **`%` → `%%`.** cmd 는 큰따옴표 안에서도 `%` 를 확장하므로, `%20` 같은 값을 그대로 두면 `%2`(인자 2)
  참조로 해석돼 주소가 조용히 망가진다.

## 6. 모호한 도메인의 처리

한 등록 도메인에 카탈로그 서비스가 여럿인 경우가 흔하다(우리은행 개인/기업, 하나은행 개인/기업/저축은행,
`fsb.or.kr` 아래 저축은행 25곳). 이때 어느 쪽 패키지를 설치할지 자동 결정할 수 없다.

- `tablecloth:https://www.wooribank.com/` → 호스트 라벨이 더 많이 일치하는 **유일 후보**가 있으므로
  개인뱅킹으로 확정된다.
- `tablecloth:https://spib.wooribank.com/…` → 개인/기업 어느 쪽과도 라벨이 더 일치하지 않아 동점이다.
  이 경우 **그 도메인으로 검색한 카탈로그 화면**을 열어 사용자가 고르게 한다(막다른 길로 두지 않는다).
- 카탈로그가 아예 모르는 도메인이면 검색 화면이 아니라 평소의 시작 화면으로 간다.

## 7. 비목표 / 한계

- **웹 페이지에서 설치 여부를 탐지할 수 없다.** 브라우저는 미등록 스킴의 실패를 스크립트에 알려주지 않아
  타임아웃 휴리스틱은 어느 브라우저에서도 안정적이지 않다. 익스텐션은 "설치판으로 열기 / 무설치 `.wsb` 받기"
  두 선택지를 함께 제공하는 편이 현실적이다.
- HKLM 전역 등록(모든 사용자)은 하지 않는다. 관리자 권한이 필요하고, per-user 설치와 범위가 어긋난다.
- 사이트 Id 와 대상 URL 을 하나의 딥링크에 함께 싣는 형태는 지원하지 않는다. 필요해지면 무설치 레인처럼
  별도 파라미터를 두는 편이 낫다.
