# 업데이트 채널 문제 해결 (미리 보기에서 안정으로 돌아오기)

> 대상: **미리 보기(Preview) 채널로 올라간 뒤 안정(Retail) 버전으로 되돌리고 싶은** 경우.
> 설계 배경은 [RELEASE_CHANNELS.md](RELEASE_CHANNELS.md).

## 1. 순서가 핵심이다

**반드시 이 순서로 하세요.**

1. **먼저 미리 보기 채널에서 빠져나온다** (아래 2절 — 옵션 창 또는 설정 파일 직접 수정)
2. **그다음** 안정 버전 설치 파일을 받아 설치한다 (3절)

순서를 뒤집으면 되돌아가지 못합니다. 안정 버전을 먼저 설치해도 **채널 설정은 그대로 미리 보기를
가리키고 있어서**, 다음 업데이트 확인에서 다시 미리 보기로 올라갑니다. 설정 파일이
`%LOCALAPPDATA%\TableCloth.Data`에 있어 앱을 지우거나 다시 설치해도 살아남기 때문입니다(설정과
즐겨찾기를 지키기 위한 의도된 동작입니다).

> **앱은 스스로 낮은 버전으로 되돌리지 않습니다.** 채널을 안정으로 바꾸면 그다음부터 미리 보기
> 업데이트를 받지 않을 뿐, 이미 설치된 미리 보기 버전이 자동으로 내려가지는 않습니다. 낮추는 것은
> 3절의 수동 설치로 합니다.

## 2. 미리 보기 채널에서 빠져나오기

둘 중 편한 방법을 쓰면 됩니다. 결과는 같습니다.

### 2-1. 옵션 창에서 (권장)

옵션 → **미리 보기** 탭 → **업데이트 채널**에서 **'안정 (권장)'** 선택. 저장 즉시 적용되며 앱을 다시
시작할 필요는 없습니다.

### 2-2. 설정 파일 직접 수정

앱이 실행되지 않거나 옵션 창에 접근할 수 없을 때 씁니다.

1. TableCloth를 완전히 종료합니다(작업 표시줄 아이콘까지 확인).
2. 탐색기 주소창에 `%LOCALAPPDATA%\TableCloth.Data` 를 입력해 이동합니다.
3. `Preferences.json` 을 메모장 등으로 엽니다.
4. `UpdateChannel` 값을 `"Retail"` 로 바꿉니다.

   ```json
   {
     "UpdateChannel": "Retail"
   }
   ```

   > 파일에는 다른 설정도 함께 들어 있습니다. **이 항목의 값만** 바꾸고 나머지는 그대로 두세요.
   > JSON 형식이 깨지면 앱이 설정을 초기화합니다(치명적이지는 않지만 다른 설정이 기본값으로 돌아갑니다).
   > 항목 자체가 없으면 추가하지 않아도 됩니다 — 없으면 기본값이 `Retail` 입니다.

5. 저장하고 앱을 다시 실행합니다.

### 2-3. 확인

옵션 창의 업데이트 채널이 **'안정 (권장)'** 으로 보이면 됩니다. 이 상태에서 업데이트를 확인하면
미리 보기 버전은 더 이상 제안되지 않습니다.

## 3. 안정 버전 설치하기

채널을 바꿨다고 이미 설치된 미리 보기 버전이 내려가지는 않습니다. 버전 자체를 낮추려면 설치 파일을
직접 받아 실행합니다.

- 릴리스 목록: <https://github.com/yourtablecloth/TableCloth/releases>
- 자산 이름 규칙: 안정은 `TableCloth_<버전>_Release_<arch>.exe`, 미리 보기는
  `TableCloth-Preview_<버전>_Release_<arch>.exe` 입니다. **이름에 `-Preview` 가 없는 것**을 받으세요.
- `<arch>` 는 x64 또는 arm64. 잘 모르겠으면 대부분 x64 입니다.

설치가 끝나면 정보(About) 창의 버전에 `-preview` 가 붙어 있지 않은지 확인하세요.

## 4. 그래도 다시 미리 보기로 올라간다면

2절을 건너뛰었거나(설치만 먼저 함) 채널이 되돌아간 경우입니다. 2절을 다시 수행하고, 필요하면
3절로 안정 버전을 다시 설치하세요.

설정을 통째로 초기화하는 방법도 있습니다. **즐겨찾기, 라이선스 동의 기록, 각종 옵션이 함께
사라집니다.**

1. 앱을 완전히 종료합니다.
2. `%LOCALAPPDATA%\TableCloth.Data\Preferences.json` 파일을 삭제합니다(폴더째 지우지 마세요 —
   카탈로그 캐시와 로그도 같이 사라집니다).
3. 앱을 다시 실행하면 안정 채널 기본값으로 시작합니다.

## 5. 참고: 왜 앱이 자동으로 처리하지 않나

"설치본이 안정이면 설정도 자동으로 안정으로" 같은 규칙과 인앱 다운그레이드를 함께 검토했지만,
의도대로 동작하지 않아 들어내고 이 문서의 수동 절차로 대신합니다. 자동 판정이 어려운 이유는,
**미리 보기로 막 전환한 사용자**(설정은 미리 보기, 설치본은 아직 안정)와 **되돌리려는 사용자**
(설정은 미리 보기, 설치본은 안정)가 겉보기에 같은 상태라서입니다. 둘을 잘못 구분하면 방금 켠
미리 보기 설정이 저절로 꺼지는 쪽이 되어 더 나쁩니다. 순서를 사용자가 정하는 편이 확실합니다.
