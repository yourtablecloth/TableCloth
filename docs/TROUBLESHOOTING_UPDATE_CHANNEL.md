# 업데이트 채널 문제 해결 (미리 보기에서 안정으로 돌아오기)

> 대상: **미리 보기(Preview) 채널로 올라간 뒤 안정(Retail) 버전으로 되돌리고 싶은데 자꾸 미리 보기로
> 다시 올라가는** 경우. 설계 배경은 [RELEASE_CHANNELS.md](RELEASE_CHANNELS.md).

## 1. 증상

- 안정 버전 설치 파일로 다시 설치했는데, 얼마 뒤 업데이트 확인을 하면 또 미리 보기 버전으로 올라간다.
- 옵션 창에서 채널을 '안정'으로 바꿔도 "업데이트가 없습니다"만 나오고 버전이 그대로다.

## 2. 왜 이런 일이 생겼나

두 가지가 겹쳐서 생긴 함정입니다.

1. **설정 파일이 재설치를 살아남는다.** 채널 선택은
   `%LOCALAPPDATA%\TableCloth.Data\Preferences.json`에 저장되는데, 이 폴더는 앱을 지우거나 다시 설치해도
   그대로 남습니다(설정과 즐겨찾기를 지키기 위한 의도된 동작입니다). 그래서 안정 버전을 재설치해도
   설정은 여전히 "미리 보기"를 가리키고, 다음 업데이트 확인에서 다시 미리 보기로 올라갑니다.
2. **되돌리는 방향의 업데이트가 막혀 있었다.** 미리 보기(예: `1.21.0-preview.1`)에서 안정(예: `1.20.9`)으로
   가는 것은 버전 번호가 **내려가는** 이동입니다. 예전 빌드는 이 하향 이동을 허용하지 않았고, 채널
   전환도 실제로는 걸리지 않아서 "업데이트 없음"으로만 보였습니다.

## 3. 지금 버전에서의 해결 (권장)

두 문제 모두 앱에서 고쳐졌습니다.

- **옵션 창에서 '안정'을 고르고 업데이트를 확인하면 그대로 안정 버전으로 내려갑니다.** 버전 번호가
  낮아지는 이동이라도 정상 동작이며, 재설치가 필요 없습니다.
- **안정 버전을 수동으로 재설치한 경우에도** 앱이 "설치본이 안정인데 설정은 미리 보기"인 상태를 감지해
  설정을 안정으로 되돌립니다(자동 옵트아웃). 다시 미리 보기로 끌려 올라가지 않습니다.

즉 대부분의 경우 **옵션 창에서 '안정' 선택 → 업데이트 확인**이면 끝납니다.

## 4. 그래도 안 되면: 수동 복구

앱이 아직 옛 버전이라 위 동작이 없거나, 설정 파일이 어긋난 상태로 남았을 때 씁니다.

### 4-1. 설정 파일에서 채널을 직접 바꾸기

1. TableCloth를 완전히 종료합니다(작업 표시줄 아이콘까지 확인).
2. 탐색기 주소창에 `%LOCALAPPDATA%\TableCloth.Data` 를 입력해 이동합니다.
3. `Preferences.json` 을 메모장 등으로 엽니다.
4. `UpdateChannel` 값을 `"Retail"` 로 바꿉니다. `LastKnownInstalledChannel` 항목이 있으면 그것도 함께
   `"Retail"` 로 맞춥니다(없으면 만들지 않아도 됩니다).

   ```json
   {
     "UpdateChannel": "Retail",
     "LastKnownInstalledChannel": "Retail"
   }
   ```

   > 파일에는 다른 설정도 함께 들어 있습니다. **이 두 항목의 값만** 바꾸고 나머지는 그대로 두세요.
   > JSON 형식이 깨지면 앱이 설정을 초기화합니다(치명적이지는 않지만 다른 설정이 기본값으로 돌아갑니다).

5. 파일을 저장하고 앱을 다시 실행합니다.

### 4-2. 안정 버전을 다시 설치하기

버전 자체가 이미 미리 보기라면, 4-1 로 채널만 바꿔도 설치된 버전은 그대로입니다. 안정 버전으로
내려가려면 최신 안정 릴리스의 설치 파일을 받아 실행하세요.

- 릴리스 목록: <https://github.com/yourtablecloth/TableCloth/releases>
- 자산 이름 규칙: 안정은 `TableCloth_<버전>_Release_<arch>.exe`, 미리 보기는
  `TableCloth-Preview_<버전>_Release_<arch>.exe` 입니다. **이름에 `-Preview` 가 없는 것**을 받으세요.
- 설치 후 4-1 을 한 번 더 확인하면 확실합니다(지금 버전은 자동으로 맞춰줍니다).

### 4-3. 설정을 통째로 초기화하기

위로도 정리되지 않으면 설정 파일을 지워 기본값(안정 채널)으로 되돌릴 수 있습니다. **즐겨찾기, 라이선스
동의 기록, 각종 옵션이 함께 사라집니다.**

1. 앱을 완전히 종료합니다.
2. `%LOCALAPPDATA%\TableCloth.Data\Preferences.json` 파일을 삭제합니다(폴더째 지우지 마세요 — 카탈로그
   캐시와 로그도 같이 사라집니다).
3. 앱을 다시 실행하면 안정 채널 기본값으로 시작합니다.

## 5. 확인 방법

- 옵션 창의 업데이트 채널이 '안정 (권장)'으로 보이는지.
- 정보(About) 창의 버전에 `-preview` 가 붙어 있지 않은지.
- 업데이트를 확인했을 때 미리 보기 버전이 제안되지 않는지.

## 6. 참고: 왜 설정을 자동으로 안 지우나

"설치본이 안정이면 무조건 설정도 안정으로" 같은 규칙을 쓰면, **미리 보기로 막 전환한 사용자**가 업데이트를
받기 전에 앱을 재시작했을 때 방금 켠 선택이 저절로 꺼져 버립니다. 그래서 앱은 "설치본의 채널이 지난번
관측과 **달라졌을 때만**" 설정을 따라가도록 동작합니다. 이 규칙의 각 경우는
`ReleaseChannelReconcilerTests` 에 테스트로 고정되어 있습니다.
